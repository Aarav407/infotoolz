# Upload product photos here

Drop your product photos in this folder, then run:

```bash
npm run import:products
```

## Naming

Name each file after the product. Examples:

- `Intel Core i7-14700K.png`
- `ASUS ROG Strix G16.png`
- `Samsung 990 Pro 2TB.png`

PNG, JPG, JPEG, and WebP are supported.

You only need the product name in the filename — category, brand, and description are filled in automatically.
